What are comparison & logical operators?
    | Operator | Meaning          | Example       |
    | -------- | ---------------- | ------------- |
    | `>`      | greater than     | `price > 100` |
    | `<`      | less than        | `price < 100` |
    | `>=`     | greater or equal | `p >= 100`    |
    | `<=`     | less or equal    | `p <= 100`    |
    | `==`     | equal to         | `p == 100`    |
    | `!=`     | not equal        | `p != 100`    |


    | Operator | Meaning           | Example           |
    | -------- | ----------------- | ----------------- |
    | `and`    | both must be True | `a > 0 and b > 0` |
    | `or`     | any one True      | `a > 0 or b > 0`  |
    | `not`    | reverse condition | `not (a > 0)`     |
