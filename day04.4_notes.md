Difference between for and while
| Feature              | `for` loop          | `while` loop  |
| -------------------- | ------------------- | ------------- |
| Number of iterations | Known               | Unknown       |
| Iterates over        | Sequence / iterable | Condition     |
| Counter handling     | Automatic           | Manual        |
| Infinite loop risk   | Low                 | High          |
| Readability          | Cleaner             | More flexible |
